# Approved headquarters supporting props

Five transparent assets extracted with the built-in image generation tool from the approved headquarters mockup. Full generation prompts are in prompts.json. The original masters remain here; cropped, transparent WebP runtime exports are in public/survival/hq-support-v1. Packaging preserves all substantial alpha components, removes detached matte specks and keeps 16 px padding.

The peg rail, supply bundle, field shelf, woven runner and boots are separate non-blocking library assets. The runner renders above the headquarters floor but below actors and furniture. The restored roof covers them all.

The user's two furniture placements currently live only in their device-local draft; the cloud snapshot still has thirteen objects without that furniture. A bounded one-time layout addition runs after the editor has selected its newest draft, and fits props to the existing chest and bench without changing any existing placement. It does not replace the user's draft with a staged map. The hqPropsVersion marker survives local storage, export/import and normal Save/Apply. Removed props stay removed. No direct server data or approval bypass is used.

Props start locked and can be unlocked, moved, resized or removed normally. Menus and inventory are not added.
