# Detailed terrain replacement

The single-image enlargement below was rejected for softness at gameplay zoom. The current `public/survival/painted-terrain-hd` set combines **16 separately reconstructed native 1254 × 1254 sections**, using built-in ImageGen. Each section covers a 1200px step plus 60px overlap padding on each side of the existing 4800px grid. Sections are fitted to 1320px for assembly (5.3% enlargement), blended over 120px, then packaged as four lossless overlapping mobile textures. This is a detailed reconstruction, not recovered original detail or a native single 4800px generation.

The 4800px world footprint, 3600px playable centre, saved object positions and custom-upload behaviour remain unchanged. Overall path routes and circle layout are retained; individual stones and leaves are newly painted. The previous source and assets remain available for rollback. `generation.json` records native dimensions of every section. `scripts/package-detailed-terrain.cjs` documents assembly. `scripts/render-terrain-detail.mjs` renders before/after terrain with the live CanvasKit adapter at 75% gameplay zoom.
